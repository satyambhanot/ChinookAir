# Design docs

Everything for the design phase goes here.

- `diagrams/` - UML exports (activity, use case, sequence, state, class, package)
- Final design document PDF goes in this folder too
- [master-plan.md](master-plan.md) - the single-person master plan mapped to the rubric (75 issues)
- [backlog/](backlog/) - the issue texts the master plan is built from
- [action-plan.md](action-plan.md) - our step-by-step plan, one issue per task
- [consistency-review.md](consistency-review.md) - the checklist of the design review and what it found
- [glossary.md](glossary.md) - the one vocabulary for diagrams, report and code
- [guideline-checklist.md](guideline-checklist.md) - every guideline requirement and the issues that cover it
- [report/](report/) - the design report in LaTeX; build it with `make pdf` (needs `latexmk` or `tectonic`)
- [requirements-map.md](requirements-map.md) - each guideline bullet and the FR that covers it
